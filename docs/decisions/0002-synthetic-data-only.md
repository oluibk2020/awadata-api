# ADR 0002: Synthetic data only in the PoC

- Status: Accepted
- Date: 2026-11-03

## Context

AwaData Commons concerns sensitive mental-health data and community governance. The current work is a demonstration, not an approved live research deployment.

## Decision

Use only fictional synthetic records. Do not import or process real participant or clinical records in the PoC.

## Consequences

The demo can validate workflow and enforcement mechanics without exposing real people. A later pilot requires separate community co-design, ethics/privacy review, security assessment and explicit operational approval.
